# ALICE source

Input to `scripts/build_alice.py`, which writes
`data/ALICE By Geography (2024).xlsx` (the file the data pipeline reads).
Retrieved 2026-09-24.

| File | What it is | Source |
|---|---|---|
| `2026 ALICE - Hawaii Data Sheet.xlsx` | United For ALICE's Hawaii data sheet from its 2026 report: households, households in poverty and ALICE households by county for 2010–2024, and by county subdivision, place and ZIP code for 2024 | "Data Sheet" link on <https://www.unitedforalice.org/state-overview/hawaii> |

County figures use American Community Survey 1-year estimates (5-year for
Kalawao, under 65,000 people); the ZIP code figures use 5-year estimates.
United For ALICE doesn't report ZIP codes with fewer than 100 households.
